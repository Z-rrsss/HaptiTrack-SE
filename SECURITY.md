# Security policy

## Supported versions

Only the latest HaptiTrack SE release receives security fixes.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature for this repository. Do
not open a public issue containing exploit details, sensitive logs or device
identifiers. Include the affected version, macOS version, reproduction steps
and impact.

For ordinary crashes, compatibility problems and DDC failures that do not
expose data or cross a security boundary, use the public issue tracker.
